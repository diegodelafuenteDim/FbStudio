# FbStudio Manual

FbStudio is a free IDE for Firebird: write and run SQL, browse and edit data, explore the database structure and look
after the server (monitoring, trace, statistics, backup and permissions), with a safety net so you don't break anything
in production. It runs on Windows, Linux and macOS, in English and Spanish.

## Chapters

1. [Getting started](01-start.md): install, register a database, connect, and the database banner.
2. [The SQL editor](02-editor.md): queries, running them, transactions, autocomplete and everything else in the editor.
3. [Results](03-results.md): the grid, filters, totals, copying, viewing values, charts and exporting.
4. [The Data tab](04-data.md): browse a table and edit it without leaving locks behind.
5. [The tree, areas and diagrams](05-tree.md): objects, DDL, dependencies, generating SQL, areas and diagrams.
6. [Monitoring and performance](06-monitoring.md): connections and transactions, trace, statistics and server details.
7. [Maintenance and permissions](07-maintenance.md): backup, restore, nbackup, validation, sweep, properties, users and permissions.
8. [Scripts, comparisons and import](08-scripts.md): the database script, comparing databases and data, documentation, importing and test data.
9. [Options, shortcuts and privacy](09-options.md): the application options, every shortcut, and what is stored where.

> **Shortcut:** in FbStudio, `F1` opens the chapter for whatever you are using, and **Help › Manual** opens this index.
