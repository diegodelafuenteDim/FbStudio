# Security

FbStudio connects to databases and stores passwords (encrypted) on your computer, so a security problem can affect real
data. If you find one, **please do not open a public issue**.

Report it privately from the repository's **Security → Report a vulnerability** tab. Describe what you found, how to
reproduce it and its impact. You will get an answer as soon as possible; once it is fixed, an advisory is published with
credit to the reporter (if they want it).

Only the latest released version receives fixes.

---

**En español:** no publiques los problemas de seguridad en un issue. Reportalos en privado desde **Security → Report a
vulnerability** en este repositorio.
